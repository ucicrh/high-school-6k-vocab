# 高中英文參考詞彙表（含中譯與例句）

- `index.html`：互動式單字表，點單字顯示中譯與例句並朗讀，可依難度排序（單一檔案，瀏覽器直接開啟）。
- `高中6K字-108版_含中譯.xlsx`：在原表加上 D 欄「中譯」與 E 欄「應用範例」。

中譯與例句由 AI 生成，並經 AI 二次審查，尚未經真人逐筆校對，可能仍有錯誤。
